# Patole Construction 🏗️

> Premium Civil Engineering, Turnkey RCC Construction & Architecture Platform

A modern, high-performance web platform built for **Patole Construction**, featuring interactive project showcases, technical blueprints, architectural services, structural evaluation requests, and seamless contact workflows.

---

## ✨ Features

- **🏠 Interactive Home Page**: High-impact Hero section, animated metric counters, architectural process workflows, and client reviews.
- **🏗️ Comprehensive Services**: Residential, Commercial, Structural RCC, and Turnkey Civil Engineering services with in-depth technical specifications.
- **📂 Full Project Portfolio & Case Studies**: Dedicated multi-page project details (`/project-view/:id`) with interactive photo galleries, engineering challenges & solutions, and dynamic switcher.
- **📐 Full-Width Creative CTA**: Edge-to-edge section with architectural construction watermark (`CTAbg.png`), 3 value pillars (Expert Guidance, Transparent Process, On-Time Delivery), direct phone action, and angled site photo.
- **💬 Direct Contact Routing**: One-click consultation booking with pre-filled project/service inquiry parameters.
- **⚡ Performance & Animations**: Lightweight animations powered by Lucide React & GSAP with responsive mobile navigation.

---

## 🛠️ Tech Stack

- **Framework**: React 18+ & Vite
- **Styling**: Tailwind CSS & Vanilla CSS
- **Icons**: Lucide React
- **Animations**: GSAP & ScrollTrigger
- **Routing**: React Router DOM v6

## 🚀 Getting Started

### Prerequisites

Ensure you have [Node.js](https://nodejs.org/) installed (v18 or newer recommended).

### Installation

```bash
# Clone the repository
git clone https://github.com/manoj-chavan-13/PatoleConstruction.git

# Navigate into the project directory
cd PatoleConstruction

# Install dependencies
npm install

# Start local development server
npm run dev
```

### Production Build

```bash
npm run build
npm run preview
```
